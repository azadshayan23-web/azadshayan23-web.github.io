## Deploy to GitHub Pages

1. Sign in to GitHub as `azadshayan23-web`.
2. Create a new **public** repository named exactly `azadshayan23-web.github.io`.
3. Upload every file and folder from this project to the repository root.
4. Commit the files to the `main` branch.
5. Open **Settings → Pages** in the repository.
6. Under **Build and deployment**, select **GitHub Actions** as the source.
7. Open the **Actions** tab and wait for the `Deploy portfolio to GitHub Pages` workflow to finish.
8. Open `https://azadshayan23-web.github.io/`.

The included workflow automatically republishes the site whenever the `main` branch is updated.
